This research aims to enhance the security of image encryption scheme using the
application of chaos theory.This image encryption scheme encompassesconfusion and 
diffusion stages. During confusion stage, three levels of shuffling using different
chaotic maps are used. In the first level, cubic map is used and Arnold cat map in 
the second level followed by tent map. Finally the shuffled image is diffused using 
Henon map to produce the ciphered image for transmission.
